# Policy Funding OS

정책자금 컨설턴트를 위한 AI 실전 코치.

DB가 들어온 순간부터 상담, 계약, 서류요청, 진행관리, 업셀링까지 하나의 AI OS에서 관리하세요.

## 기술 스택

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
- ESLint

## 개발

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

## 빌드

```bash
npm run build
npm run start
```

## 배포

[Vercel](https://vercel.com)에 저장소를 연결하면 별도 설정 없이 바로 배포됩니다.
